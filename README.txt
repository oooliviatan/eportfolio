SMART FITNESS FYP PORTFOLIO

FILES
- index.html: all website content
- style.css: website design and responsive layout
- script.js: mobile menu, navigation highlight and scroll animation
- assets/: place your own images, PDF files and screenshots here

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in Chrome.
3. You can also open the folder in Visual Studio Code and use the Live Server extension.

WHAT TO CHANGE
Search in index.html for:
- YOUR NAME
- YOUR MATRIC NUMBER
- YOUR SUPERVISOR NAME
- your-email@example.com
- YOUR-USERNAME
- YOUR-REPOSITORY
- VIDEO_ID

HOW TO ADD SCREENSHOTS
The current website displays labelled placeholders.
To use real images, replace a placeholder, for example:

<div class="system-shot image-placeholder">
  <span>LOGIN SCREENSHOT</span>
  <code>assets/login.jpg</code>
</div>

with:

<img class="system-shot real-image" src="assets/login.jpg" alt="Login page screenshot">

Then add this to style.css:

.real-image {
  width: 100%;
  min-height: 380px;
  object-fit: cover;
  border-radius: 24px;
  border: 1px solid #dce4e1;
}
