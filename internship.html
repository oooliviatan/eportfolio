Overall Internship Reflection

01 Skills developed

Throughout my internship, I developed both technical and problem-solving skills through involvement in an AI-powered telecommunications service request automation project. I gained practical experience in Python programming, geospatial analysis, API integration, and AWS cloud services, particularly Amazon Bedrock and DynamoDB. I also learned how to work with different technologies, including Google Geocoding API, OSRM, and the Haversine formula, to support geographical validation and route analysis. In addition, I improved my understanding of AI agent development, workflow orchestration, JSON data processing, Excel automation, and PowerPoint document generation.

02 Challenges faced

One of the main challenges I encountered was working with unfamiliar technologies and understanding how different components could be integrated into a complete automated workflow. Geospatial route generation was particularly challenging because OSRM did not always produce routes that matched the expected road alignment and project-specific requirements. Another limitation was the use of confidential live project data, which restricted access to actual customer information and required the use of synthetic or sample data for development and testing. Furthermore, cloud integration involved additional technical requirements, including AWS permissions, configurations, and infrastructure dependencies.

03 Lessons learned

Through this internship, I learned that developing an automation solution requires more than just writing code or implementing AI models. It is important to understand the business requirements, organise data properly, validate system outputs, and ensure that different components communicate effectively. I also realised that AI-generated results are not always accurate or consistent, especially when handling geographical information, and therefore require additional validation and deterministic logic. Most importantly, I learned to approach unfamiliar technical problems independently, conduct research, perform testing, and seek guidance from team members when necessary.

04 Next focus / areas for improvement

Moving forward, I would focus on improving the accuracy and reliability of the geospatial routing process, particularly in handling road alignment, junctions, and infrastructure connectivity. Further improvements could also be made to the integration of specialised AI agents and AWS cloud services to create a more stable and scalable automated workflow. Additionally, conducting a formal performance comparison between the existing manual process and the automated solution would help evaluate the actual efficiency improvements. However, this would require suitable test data and recorded processing times, which were not established during the current project period.
